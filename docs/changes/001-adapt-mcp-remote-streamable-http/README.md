# Change 001: Adapt MCP Server for Remote Streamable HTTP Access

## Summary
Adapts the Jira MCP server from a local `stdio` transport to **Streamable HTTP** transport (`/mcp` endpoint on port `8080`), enabling remote AI clients to access Jira tools over the network.
